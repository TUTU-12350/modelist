# 模力榜 Modelist

一个以 `index.html` 为入口的 AI 模型目录与评分社区。原生 HTML / CSS / JavaScript，无需前端构建、npm 安装或外部字体。

## 启动完整网站

需要 Python 3.10+，不需要 pip 依赖。在项目目录运行：

```powershell
python server.py
```

在浏览器访问 **http://127.0.0.1:8080**。

- 搜索名称、中文别名、厂商、功能、使用场景，支持分类和条目类型筛选。
- 模型详情包含功能、官方链接、资料核对日期与使用版本说明。
- 注册账号后可发布 1–5 星点评，并编辑、删除自己的点评。
- 点评存入 SQLite。同一服务上的所有访客无须登录即可查看，不同浏览器可以共享数据。
- 同一用户对一个条目保留一条点评，修改后重新计算平均分。没有预置的虚假分数或点评。
- 最新点评、口碑榜、我的点评、当前浏览器收藏、移动端布局均可用。
- 页面每 15 秒拉取新点评；重新打开详情或刷新页面可看到最新记录。写点评时不会因轮询丢失草稿。

账号由本站管理，首次使用点“注册账号”。请用试用账号；此版本没有邮箱验证、密码找回或账号注销入口。

## 直接打开 index.html

直接双击 `index.html` 可体验完整界面、搜索、收藏、本地身份与点评。界面会明确显示“本地预览”。

**直接打开 HTML 的点评只存于本浏览器，不会成为互联网公开评论。** 本地身份不是安全认证，不要求输入密码。仅部署静态 HTML 也不能提供真实公开评分服务。通过普通静态 HTTP 服务打开时，页面会提示社区接口未连接，不会把提交的点评悄悄保存到另一处。

本地预览数据与服务器数据分离，不自动迁移，以免把测试内容发布为真实点评。

## 局域网试用

```powershell
python server.py --host 0.0.0.0 --port 8080
```

同一网络内的其他设备使用 `http://你的电脑局域网IP:8080` 访问。电脑与 Python 服务需要持续运行；是否可访问取决于防火墙和网络设置。默认只监听本机，不会自动向公网发布。

## 数据与配置

- `index.html`：样式、图标、目录数据和前端交互全部包含在同一文件。
- `server.py`：标准库 HTTP 服务、注册登录、会话、评分 API、SQLite 持久化。
- `data/modelist.sqlite3`：首次运行时创建，包含用户、登录会话与点评；不纳入 Git。
- `tests/test_server.py`：匿名公开读取、多用户隔离、修改删除、重启持久化、非法输入和跨站请求测试。
- `PUBLIC_ORIGIN`：部署到反向代理后设置完整外部来源，例如 `https://your-domain.example`。HTTPS 来源会启用 Secure Cookie。服务不信任客户端传入的转发头。
- `--db path`：指定数据库文件路径，适合独立测试。

密码使用随机盐和 PBKDF2-SHA256（600,000 次）存储。会话 Cookie 使用 HttpOnly、SameSite=Lax，状态更改需要同源请求和 CSRF Token。写入验证在服务端进行，SQLite 查询使用参数绑定，前端转义用户内容。服务只允许访问首页和 API，不会公开项目文件或数据库。

备份时先停止服务，再复制整个 `data` 文件夹；运行中请使用 SQLite 的 backup API，避免只复制主文件而遗漏 WAL 数据。

## 目录维护

当前收录 12 个常见条目，资料于 2026-09-09 核对，官方来源链接在每个详情中。采用模型系列或产品级别的收录，不宣称覆盖所有最新型号。点评可附使用版本，系列平均分会汇总该系列的不同版本体验。

编辑 `index.html` 中的 `MODELS` 数组可以更新简介、标签、分类和官方来源。添加新条目时，同时更新 `server.py` 的 `MODEL_IDS` 白名单及首页计数。请勿把未验证的“最新版本”、价格或测试分数直接作为事实写入目录。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试使用临时数据库，不会向正常站点插入测试评论。浏览器验证脚本和截图在 `tests/browser.cjs` 与 `test-results/`（若已生成）。

## 公开上线前

本版本完成可运行的网站与共享评分核心流程，适合本机和小范围试用。Python 标准库 HTTP 服务不是为大规模生产流量设计的。

公开上线需要部署持久运行的后端、配置域名与 HTTPS，并根据实际流量补充成熟的应用服务、分页和并发控制。还需完成运营者联系渠道、举报与内容审核、账号恢复/注销及数据库备份。前端页面保持 `index.html`，后端可换为生产服务或托管数据库 API。当前代码不包含在线审核后台，不会自动部署或购买服务。
